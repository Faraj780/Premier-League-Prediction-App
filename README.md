# Premier-League-Prediction-App
Machine learning project using Python, Pandas and Sci Kit Learn, using data from past premier league seasons to predict future matches.

## Setup

Install the project dependencies before running the scraper:

```bash
python3 -m pip install -r requirements.txt
python3 Scraper.py
```

The `urllib3` 1.x constraint keeps this project compatible with the LibreSSL runtime bundled with macOS's system Python. A Python installation linked against OpenSSL 1.1.1 or newer can use `urllib3` 2.x instead.
